# DB 재분할 — 스냅샷 층을 걷어내고 코퍼스별 파일 넷을 그대로 읽는다

## Context

어제(#2·#4) 국회·법령·소관기관을 매일 한 파일 `법.db`로 접는 스냅샷 층을 만들었다. 근거는 교차 뷰(법안 ↔ 현행 조문)였는데, 성진의 판단은 그 교차를 볼 일이 드물고 스냅샷 층이 관리 복잡도만 올린다는 것이다 — 실제로 첫날부터 주석 패치 드리프트(A0)·4.6GB 스테이징·checkout 삭제 사고가 그 층에서 났다. 다음 브리프(`.tmp/260912_law db 개선.md`)가 법령 스키마 전면 재설계를 예고하고 있어, 스냅샷 층이 남으면 그 재설계를 원천 스키마와 패치 목록 두 곳에서 해야 한다.

**목적 한 문장.** `DBs/` 아래를 `NEWS.db`·`CONGRESS.db`·`LAW.db`·`AGENCIES.db` 넷으로 되돌리고, 스킬이 수집기 DB 파일을 레시피 하나로 직접 읽게 하며, 스냅샷이 독자를 위해 만들던 것 중 코퍼스 하나 안에서 성립하는 것(신선도·독자용 주석)은 수집기 스키마 자체로 옮긴다.

**결과.** `snapshot.py`와 그 테스트·워크플로 스텝이 사라지고, 네 파일이 같은 URI 모양으로 열리며, 수집기 DB의 `.schema`가 의원실 독자에게 바로 읽힌다. 표·컬럼 설계는 손대지 않는다(#2의 것).

### 잔여 위험 (수용됨)

- **R1 (R2 확장)** 라이브 DB에 immutable 경계가 없다. `query_only`는 같은 SQL 문자열 뒤에 `PRAGMA query_only=0; …`을 이어 쓰면 뚫린다. 막는 것은 레시피와 `allowed-tools` 모양뿐이고, 회복 수단은 02:40 백업 사다리(세대별 검증본). 훅·래퍼는 D9(이전 계획)대로 두지 않는다 — 필요해지면 그때 연다.
- **R2** 수집 중(04:17~08:30 KST)에 읽으면 문장 단위로만 일관된다(WAL). 하루 한 판본 고정은 없다. 클로드의 열린 연결이 체크포인트 TRUNCATE를 막아 `-wal`이 남을 수 있는데, `backup.py`는 사이드카를 보고 URI를 고르므로 무해하다.
- **R3** 교차 질의는 ATTACH로 손으로 한다. 한 파일 안의 뷰가 다른 파일을 못 보므로 "법안이 고치려는 법의 조문"은 두 질의다.
- **R4** `.schema` 지도가 셋으로 나뉜다. 어느 파일에 무엇이 있는지는 파일 이름과 3절 라우팅 한 문장이 진다.

## 설계

### 읽기 레시피 하나 (A2)

```
sqlite3 -box "file:${CLAUDE_SKILL_DIR}/DBs/<NEWS|CONGRESS|LAW|AGENCIES>.db?mode=rw" "PRAGMA query_only=1; <SQL>"
```

이유 두 문장이 본문에 남는다: `mode=ro`는 `-wal` 없는 WAL DB에서 죽고(F2), `mode=rw`는 없는 경로를 거부해 유령 0건이 없다(F3). `query_only`는 쓰기 경계이므로 명령의 첫 문장이다. 교차는 같은 명령 안에서 `ATTACH 'file:${CLAUDE_SKILL_DIR}/DBs/LAW.db?mode=rw' AS 법령;`을 앞에 두고 `법령.표`로 부른다(D5, F3).

### `신선도` 뷰 (D3·A3) — 각 수집기 SCHEMA 상수에

국회(`congress/db.py` SCHEMA 끝, `DROP VIEW IF EXISTS 신선도;` 쌍으로):

```sql
CREATE VIEW 신선도 AS
  -- **이 답은 언제 기준인가.** 항상 한 행이다. 시점을 묻는 질의는 여기서 끝난다.
  -- (컬럼 주석은 snapshot.py:142-152 의 문장을 옮긴다 — 감사통과 0 의 뜻, 감사시각과 적재기준시각의 간극, 경고의 뜻)
  SELECT (SELECT MAX(수집시각) FROM 의안) AS 적재기준시각,
         CASE WHEN g.상태 IS NULL THEN NULL WHEN g.상태='완료' AND COALESCE(g.건수,0)=0 THEN 1 ELSE 0 END AS 감사통과,
         g.갱신일시 AS 감사시각,
         COALESCE(g.상세, CASE WHEN g.건수>0 THEN '게이트 위반 '||g.건수||'건' END) AS 감사상세,
         (SELECT CASE WHEN COUNT(*)>0 THEN '마지막 수집이 '||group_concat(대상,'·')||' 를 건너뛰었다 — 정당·현직여부·위원회 배정이 옛 값일 수 있다. 발의·표결·발언 이력은 영향받지 않는다.' END
            FROM 수집상태 WHERE 상태='건너뜀') AS 경고
```
